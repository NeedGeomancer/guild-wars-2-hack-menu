## 🧩 About

**Guild Wars 2 overlay** is a curated list of Guild Wars 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, event timer, map markers
- **Quality-of-Life Helpers** — build catalog, skin manager, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Gameplay Helpers
- Event Timer — track world boss and meta event windows
- Map Markers — annotate gathering nodes and waypoints
- Route Notes — record and review exploration paths
- Speed Control — adjust movement playback for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Skin Catalog — browse armor skins, dyes, and weapon sets
- Build Notes — organize trait and gear loadouts
- Visibility Boost — improved marker contrast on busy maps

### 🏋️ Practice Layout
- Practice Notes — segment study on any map layout
- Camera Control — manually adjust camera angle for study
- Input Buffer Notes — chain complex maneuvers in the training area
